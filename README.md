# Rock vs Mine Classification

This project uses Machine Learning to classify sonar signals as either Rock or Mine.

## Dataset

The dataset contains 208 samples and 60 features representing sonar signal patterns.

## Machine Learning Algorithm

- Logistic Regression

## Libraries Used

- NumPy
- Pandas
- Scikit-learn

## Project Workflow

1. Import required libraries
2. Load the sonar dataset
3. Explore the dataset
4. Perform statistical analysis
5. Split the data into training and testing sets
6. Train the Logistic Regression model
7. Make predictions
8. Evaluate model accuracy
